# Chatbot

This project aims to build a chatbot that simulates the thinking and communication style of Dr. Anand Deshpande, inspired by his "2nd Orbit" talk. The chatbot will take user queries and respond using insights extracted from his philosophies and leadership principles.

## Reference Material
- https://www.youtube.com/watch?v=9jz8ijBaF9s

## Project Tasks
Task 1 — Problem Definition:
Define what the chatbot should do, what inputs it will take, and what outputs it will generate.

Task 2 — Data Extraction:
Convert the video/audio to text and organize the cleaned content for further use.

Task 3 — Knowledge Base Creation:
Create a structured knowledge document containing all relevant insights for the chatbot.

Task 4 — System Architecture Planning:
Plan the UI, backend logic, model connectivity, and context-handling approach.

Task 5 — Prompting Strategy Design:
Develop the system prompt and define how contextual data will be dynamically added.

Task 6 — Implementation Plan:
Select the model and tools, define modules to build, and outline the testing process.
